# Programming Expert (GEMINI.md)

## Purpose
This MCP server provides authoritative guidance on programming languages, official specifications, industry best practices, and idiomatic design patterns.

## Usage for Agents
- Use `get_language_guidance` to retrieve links to official docs and grammar specs for languages like Java, Go, C++, Python, etc.
- Use `get_pattern_guidance` to understand how to correctly implement design patterns (e.g., Singleton, RAII) according to a language's specific idioms.
- This is a critical resource for ensuring code correctness and professional standards.

## Supported Languages
- Java, Go, C, C++, JavaScript, TypeScript, Node.js, Python, PowerShell.
